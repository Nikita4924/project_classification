# project_classification

## Описание проекта
Проект по оценке эмоциональной окраски текстовых сообщений (sentiment analysis или emotion detection) представляет собой классическую задачу NLP в машинном обучении. 
Он включает определение эмоций (например, радость, гнев, грусть) или тональности (позитив/негатив/нейтраль) в текстах, с учетом специфики русского языка.

## Предварительный план проекта:
### Цели:
Классификаццировать 3-6 эмоций (нужно опредлить какие). Проверку выполнять на коротких текстах (твиты?\сообщения ВК?)
Метрики успеха - (F1-score > 0.75) 

### Шаги:
1. Сбор и анализ данных

2. Предобработка данных

3. Выбор и обучение модели

4. Оценка и оптимизация

5. Развертывание и презентация

## Базовая структура проекта:
```
project_classification/
├── data/               # Исходные и обработанные данные
│   ├── raw/            # Необработанные данные (read-only)
│   └── processed/      # Предобработанные данные для обучения
├── models/             # Сохраненные веса моделей и артефакты (.pkl, .revmod)
├── notebooks/          # Jupyter ноутбуки для экспериментов и EDA
├── src/                # Исходный код модуля
│   ├── __init__.py
│   ├── data_loader.py  # Загрузка и очистка данных
│   ├── features.py     # Векторизация и инженерия признаков
│   ├── models.py       # Определения моделей (в т.ч. Manual Logistic Regression)
│   └── train.py        # Основной цикл обучения
├── tests/              # Юнит-тесты
├── main.py             # Точка входа для запуска обучения/предикта
├── requirements.txt    # Список зависимостей
└── README.md           # Документация проекта
```
